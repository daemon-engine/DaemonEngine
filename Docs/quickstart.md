# Quick start

## Prerequisites

- Windows 10 or later
- Visual Studio 2019 or later, with C++20 support
- Git

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/daemon-engine/DaemonEngine.git
   cd DaemonEngine
   ```

2. Open the solution in Visual Studio: go to the `Code` folder and open `Engine.sln`.
3. Choose the `x64` platform and a `Debug` or `Release` configuration, then build the solution
   (Ctrl+Shift+B).
